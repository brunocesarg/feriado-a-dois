# Feriado a Dois

Plano de viagem para o feriado de Carnaval de 2027 (4 a 9 de fevereiro): destinos de praia para descansar, em até R$ 6 mil para o casal.

Abra no iPhone pelo Safari e use **Compartilhar → Adicionar à Tela de Início** para abrir em tela cheia.
